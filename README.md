# A 股行业轮动与资金流向监控仪表盘

单文件 HTML 的 A 股盘面工作台：大盘概览、31 个申万一级行业热力、主力资金排行、风格轮动、北向资金、个股 K 线与压力位计算、消息面实时快讯，以及独立的**策略回测工作台**与**策略实验室**（写策略 → 参数寻优 → 全市场选股 → 每日自动优化）。深色金融终端风，A 股惯例**涨红跌绿**。

打开 `ashare-sector-rotation-dashboard.html` 即可用，无构建、无依赖、无后端（消息面面板需本地启动 `news-live`）。页头三个标签切换「盘面」「回测」「策略实验室」，互相独立、不挤在同一屏。

## 功能

**1. 大盘概览** — 上证 / 深证成指 / 创业板指 / 科创50 / 沪深300 / 上证50 / 中证1000 / 中证500 / 北证50，含沪市成交额。

**2. 消息面 · 实时快讯** — 财联社电报 + 东财快讯聚合，按关键词判定利好 / 利空 / 多空交织 / 中性，自动标注命中的个股。支持六个过滤页签（全部 / 利好 / 利空 / 多空交织 / 命中个股 / 本股资讯），60 秒自动刷新；本股资讯与下方 K 线的标的选择联动。

**3. 行业热力** — 31 个申万一级行业，色深映射涨跌幅强度，格内附主力净额。

**4. 主力资金排行** — 双向条形，两侧独立刻度（电子这类百亿级流出与其他行业混用同一坐标轴会把小行业压扁）。

**5. 风格轮动** — 大盘价值 / 小盘成长等风格指数强弱对比，四象限罗盘。

**6. 个股 K 线工作台** — 输入代码 / 名称 / 拼音首字母搜索（`600519` / `茅台` / `gzmt`），日 / 周 / 月 K × 60/120/250 根，前复权，MA5/10/20/60 + 成交量副图 + 十字光标读数。

**7. 压力位 / 支撑位** — 多算法投票标注强度：前高前低、均线 / BOLL 通道、筹码密集区（成交量加权）、ATR 波动通道、整数关口。编号规则 R1 / S1 为最近价位，按距离排序，实时价逼近时高亮。

**8. 回测工作台**（独立页面，页头标签切换）

四套规则化策略，思路取自 PA（价格行为）体系：EMA20 趋势跟随、均线交叉、N 日区间突破、突破回踩再入场。

撮合与成本按 A 股实际约束建模：

- 信号在 **K 线收盘确认**，**次日开盘成交**（符合 T+1，不允许当日进出）
- 佣金（万分比，最低 5 元）+ 卖出印花税 0.05% + 双边滑点，均可调
- 买入按**整百股**取量，资金不足一手则放弃该信号
- 盘中止损 / 止盈按 2×ATR 与 2R 默认参数，跳空穿越按开盘价成交；同一根 K 线同时触及止损与止盈时**先算止损**（保守口径）
- 可选 ATR 跟踪止损

输出：策略收益 / 年化 / 买入持有 / 超额、胜率、盈亏比、利润因子、最大回撤、夏普（年化 √250）、平均持仓，资金曲线（含买入持有基准）、带买卖标记的 K 线叠加图、逐笔交易明细（入场出场日期价格、盈亏、持仓周期、出场原因）。

K 线图的标注口径：

- **▲ 买入**：画在成交那根 K 线的最低价下方，青色，标签「买 成交价」
- **▼ 卖出**：画在成交那根 K 线的最高价上方，盈利为红、亏损为绿，标签「卖 成交价 ±x.x%」（区间放不下时自动退化为「卖 成交价」或「卖」，多笔挨在一起时自动上下错行避让）
- **图形下沿彩带**：每笔持仓的时间区间，红=盈利、绿=亏损，不遮挡 K 线
- **鼠标悬停**：指到 ▲/▼ 上弹出该笔明细（入场日期价格、出场日期价格、盈亏率与盈亏额、持有 K 线数、出场原因）
- 标注太密时可以点图例右侧「**价签 · 开/关**」一键关掉文字，只留三角

支持深链：`...html?page=bt&btq=601899&run=1` 打开即对该标的自动回测；`btq` 也接受名称或拼音。

**自定义策略（`✎ 自定义脚本`）** —— 不想被四个内置策略限制时，直接在页面里写：

```js
/* 收盘评估 → 次日开盘成交（T+1） */
function buy(i){                     // 空仓时每根 K 线调用一次
  return C[i] > HH(i, 20);           // 收盘突破前 20 根最高价
}
function sell(i, pos){               // 持仓时每根调用，pos = { entry, i, sh, stop, tp }
  return C[i] < LL(i, 10) || C[i] < EMA(i, 20);
}
```

脚本环境（`new Function` 注入，strict 模式）：

| 名称 | 说明 |
|---|---|
| `C[i] O[i] H[i] L[i] V[i]` | 收盘 / 开盘 / 最高 / 最低 / 成交量 |
| `D[i]` | 日期字符串，如 `'2026-11-16'` |
| `EMA(i, n)` / `ATR(i, n)` | n 周期均线 / 真实波幅均值（按需计算并缓存） |
| `HH(i, n)` / `LL(i, n)` | 前 n 根（**不含当日**）最高 / 最低 |
| `MACD(i)` | `{ dif, dea, bar }`，12/26/9 标准口径（DEA 从 DIF 首个有效点起算） |
| `KDJ(i[, n])` | `{ k, d, j }`，默认 9,3,3，平滑 1/3、初始 50 |
| `pos` | 仅 `sell` 里可用：`{ entry 入场价, i 入场下标, sh 股数, stop 止损位, tp 止盈位 }` |

- 上方 ATR / 止损 / 止盈参数对自定义策略同样生效，填 `0` 关闭；仓位仍是**全仓**模型
- 脚本存 `localStorage`，下次打开还在；`Tab` 缩进、`Ctrl+Enter` 直接运行
- 语法错直接报原因；运行期出错会指出**具体哪一天**（如「脚本在 2025-08-18（第 31 根 K 线）抛错：foo is not defined」）并终止
- 「MACD+KDJ共振」按钮一键载入双金叉共振模板：`buy` = 最近 3 根内 MACD 与 KDJ 先后金叉（窗口可调），`sell` = 任一死叉离场
- 默认模板就是内置的 EMA20 策略，两者回测结果**逐项一致**（同一套撮合/费用代码），可用来验证脚本写对没有

**9. 策略实验室**（独立页面，页头第三个标签）

把「写策略 → 调参数 → 选股 → 每天自动跑」连成一条流水线，全程在本机浏览器完成，不依赖任何后端或大模型接口。

- **写策略**：与回测页同一套脚本环境（`C/O/H/L/V/D`、`EMA/ATR/HH/LL/MACD/KDJ/RSI`、`pos`），额外提供 `P.p1 / P.p2 / P.p3` 三个**可优化参数**；内置四套模板（双均线金叉 / N 日突破 / MACD+KDJ 共振 / RSI 超卖+趋势），也可直接让 AI 按中文描述生成脚本贴进来
- **参数网格寻优**：对 `P.p1~P.p3` 的「最小 / 最大 / 步长」做笛卡尔网格搜索，目标可选**夏普 / 策略收益 / 收益÷回撤**，结果按目标排序给出前 12 组（收益、年化、夏普、回撤、笔数、胜率、同期买入持有），点「应用」把参数写回当前值。撮合口径与回测页**完全一致**（同一套 T+1 / 费用 / 整百股 / 止损止盈代码，已交叉验证逐项相同）
- **全市场信号选股**：先按实时行情快筛（成交额、价格区间、涨跌幅、剔除 ST/退市、是否含北交所），取成交额最大的 N 只（默认 40），逐只拉日 K 用你的 `buy` 判定信号是否成立；结果给出代码 / 名称 / 现价 / 涨跌 / 成交额 / 换手 / 信号 K 线日，并可直接「回测」或「看 K 线」
- **每日记录**：寻优 + 选股结果写入本机 `localStorage`（60 天滚动），表格里能看到每天用的参数、样本内表现、信号股清单——参数漂移突然变大就是过拟合的预警信号
- **无人值守**：`每日策略优化.bat` 双击 = 打开浏览器自动跑一遍；`每日策略优化.bat report` = 无头静默跑完，把当天结果写成 `lab_reports/YYYY-MM-DD.md`（可直接挂 Windows 计划任务）

无人值守跑的策略来自 `lab_config.json`（`strategy` 脚本 + `params` 搜索范围 + `bench` 基准标的），改这个文件就是改每天自动优化的策略；交互使用时则以页面里编辑的脚本为准（存 `localStorage`）。

## 快速开始

Windows：

```
双击 打开仪表盘.bat
```

它会做三件事：找到装了 `akshare` 的 Python → 若 8510 端口空闲则以最小化窗口启动 `news-live` 新闻服务 → 用 Edge / Chrome 打开仪表盘（本机 `.html` 默认关联 IE，脚本会显式绕开）。

其他平台或手动启动：

```bash
# 只开仪表盘：直接用浏览器打开 html 即可，指数/行情/K线照常工作
open ashare-sector-rotation-dashboard.html

# 需要消息面面板时再启动本地新闻服务
cd news-live
pip install -r requirements.txt
python server.py          # 127.0.0.1:8510
```

服务未启动时，消息面板会显示启动指引并每 25 秒重试，不影响其余区块。

### 被拦截的网络环境（预览面板 / 内嵌 webview / 公司网络）

预览面板这类嵌入窗口通常会禁掉页面对外部接口的直连（CSP 或出口策略），表现为三个数据源全 ✗、页面只剩离线快照。为此 `news-live` 兼作**行情中转**：

```
http://127.0.0.1:8510/api/relay?u=<原接口地址，URL 编码>
```

页面在直连失败时自动改走这里（`RLY` / `NET` 状态机 + 白名单：腾讯、东财、新浪的行情域名），由本机 Python 代取后**原样回传字节**（GBK 编码不动，前端解码逻辑完全不变），JSONP 则在本地剥壳后解析。命中后页脚出现 `⇄ 本地中转` 标记。

- 只在 `127.0.0.1` 上响应（不是公网代理），单 IP 每分钟 3000 次、单响应上限 4 MB
- 中转服务没启动时静默降级回原来的直连路径，零影响
- 自定义策略脚本用 `new Function` 编译，若窗口的 CSP 缺 `unsafe-eval` 会给出明确提示——那种情况下只能换系统浏览器

深链：`...html?q=紫金矿业` 或 `...html#601899` 打开即加载该股。

## 数据源与口径

| 数据 | 主源 | 备源 |
|---|---|---|
| 宽基指数、个股行情、风格指数 | 腾讯财经（`fetch` + CORS，GBK 手动解码） | 东方财富 JSONP |
| K 线（日 / 周 / 月，前复权） | 腾讯 `ifzq.gtimg.cn` | `web.ifzq.gtimg.cn` → `proxy.finance.qq.com` 自动降级（`web.ifzq` 会周期性命中腾讯 WAF，返回 501 跳转页；代码里按域名顺序重试并记住可用源） |
| 股票搜索（代码 / 名称 / 拼音首字母） | 页面内置全量索引（5579 只，离线可用） | 腾讯 smartbox（补全拼与跨市场） |
| 行业涨跌 + 主力净额 | 东方财富 `push2/clist`（`f62` 字段独有） | 页面内置快照 |
| 快讯 | `news-live` 本地服务（财联社 + 东财快讯） | — |
| 以上全部（直连被拦时） | `news-live` 的 `/api/relay` 本机中转 | 离线快照 |

几个必须说清的口径问题：

- **北向「每日净买入」已不存在。** 2024-08-19 起沪深港交易所取消每日净买入披露，只保留成交总额、十大活跃股、季度持仓。页面不展示第三方估算的「净流入」数字，改用成交额 + 活跃股 + 季度增持三件套。
- **主力资金有两套口径。** 行业明细加总与全市场统计因大单阈值、机构席位处理不同，方向一致但量级有别；页面统一用同一套做行业间横向比较，脚注标明差异。
- **成交额不反映方向。** 十大活跃股里的高成交可能是外资在下跌方向上做高换手，不等于抄底。
- **情绪标签是关键词规则判定**，不是人工标注，当作线索而非结论。

## 已知限制

- 行业热力与主力资金依赖东财 `clist` 端点；该端点对部分 IP 会临时限流，此时自动降级为内置快照并显式标注日期，不会静默假装实时。
- 腾讯接口没有申万一级行业指数，也没有同口径的板块主力净额，因此这两块没有等价的替代源。
- 行情为公开接口转发，非交易所直连，通常有 3–15 秒延迟。
- **搜索走本地索引，不依赖网络。** 页面内置 5579 只 A 股（代码 + 名称 + 汉字→拼音首字母表，约 110 KB），支持 `600519` / `6005` 代码前缀、`茅台` 名称子串、`gzmt` 拼音首字母；腾讯 smartbox 只用于补全拼（`maotai`）和跨市场标的，接口不可达时本地结果照常返回。新股上市后需刷新索引：`py -3.10 build_stock_index.py`（依赖 akshare + pypinyin）。
- 回测为**单标的、全仓、多头**的规则化模拟：不含分红送转的现金处理、不含融资融券、不做仓位管理与组合分散；参数在同一段历史上择优极易过拟合，样本外表现通常明显劣于样本内。
- 策略实验室的寻优是**样本内择优**，输出的是「这段历史上最好的一组参数」，不是「未来最好的参数」；全市场选股的信号只代表规则成立，不含基本面、流动性冲击与涨跌停无法成交的约束。把它当选股线索，不要当买入指令。

## 目录结构

```
ashare-sector-rotation-dashboard.html   # 仪表盘（单文件，含全量股票索引 + 回测 + 策略实验室）
build_stock_index.py                     # 刷新内置股票索引（新股上市后跑一次）
打开仪表盘.bat                           # Windows 一键启动器
每日策略优化.bat                         # 策略实验室每日优化（双击=可见运行；report=无头生成日报）
lab_config.json                          # 无人值守用的策略脚本 / 参数范围 / 基准标的
lab_reports/                             # 每日优化日报（YYYY-MM-DD.md）
news-live/
  server.py                            # 本地快讯服务 + 行情中转（127.0.0.1:8510）
  requirements.txt                     # akshare / pandas / requests
  radar/                               # 新闻抓取、个股映射、多空判定
  static/index.html                    # 独立的快讯网页版
```

`news-live/radar` 的数据层与 [alpha-radar](https://github.com/morningddy/alpha-radar) 同源，此处为随包分发的独立副本。
